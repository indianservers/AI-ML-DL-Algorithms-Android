# Visualization differentiation matrix

This matrix describes the mechanism a student must see, the implementation route in the current source, and the remaining verification. A distinct title or icon is not evidence of a distinct algorithm. The route inventory is in [FinalAlgorithmVisualizationAudit.md](FinalAlgorithmVisualizationAudit.md). Runtime control attempts are logged in the `qa/final-emulator-*.csv` sweep files; they are not a numerical correctness proof. Every unique topic has a saved screenshot, but full-resolution per-screen comparison remains open.

## Verification rule

Mark a family fully reviewed only after its compared screens are inspected in the emulator, a defining interaction changes the displayed algorithm state, and a numerical or structural assertion covers its defining mechanism. The current matrix deliberately leaves those checks pending where the evidence does not yet exist.
