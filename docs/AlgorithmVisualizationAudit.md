These are the mechanism distinctions checked against native routes, calculations, and saved device views. The examples are educational demonstrations rather than framework-equivalence tests.

| Comparison | Distinction visible in the app |
|---|---|
| Monte Carlo / TD | End-of-episode return / immediate bootstrapped transition update |
| SARSA / Q-Learning / Expected SARSA | Sampled next action / greedy max target / policy-weighted expected value |
| DQN / Double DQN | Q network and target / online selection with separate target evaluation |
| DQN / Dueling DQN | Direct Q outputs / value and advantage streams combined into Q |
| A2C / A3C | Synchronous worker batch / asynchronous shared-model worker updates |
| DDPG / TD3 | Actor and one critic / twin critics, delayed actor and target smoothing |
| PPO / SAC | Clipped probability ratio / entropy-regularized stochastic policy |
| Model-free / model-based RL | Direct policy or value update / learned transition rollouts for planning |
| Imitation / inverse RL | Learn policy from demonstrations / infer reward from demonstrations |
| MLE / MAP | Likelihood optimum / likelihood multiplied by prior |
| MCMC / Gibbs / Metropolis-Hastings | Sampling chain / conditional coordinate samples / proposal and acceptance |
| Momentum / Nesterov | Velocity with current gradient / lookahead gradient |
| Adam / AdamW | Adaptive moments / separately decoupled weight decay |
| Newton / BFGS / L-BFGS | Explicit second derivative / inverse-Hessian estimate / limited-memory history |
| Genetic Algorithm / Differential Evolution | Parent crossover / scaled vector-difference trial |
| PSO / Genetic Algorithm | Social and personal velocity / selection, crossover and mutation |
| ACO / PSO | Pheromone on graph routes / particles moving by velocity |
| User CF / item CF | Similarity between users / similarity between rated items |
| Matrix factorization / Neural CF | Latent-vector dot product / nonlinear embedding interaction |
| Feature / permutation importance | Model contribution / score drop after feature shuffle |
| SHAP / LIME | Additive attribution from baseline / weighted local surrogate fit |
| Saliency / Grad-CAM | Input-pixel gradients / class-weighted activation map |
| BFS / DFS | FIFO level order / LIFO depth-first frontier |
| UCS / Greedy / A* | Path cost g / estimate h / combined f = g + h |
| A* / SMA* | Unbounded frontier / bounded frontier with forgotten-leaf backup |
| Minimax / Alpha-Beta | Full value backup / same value with cut branches |
| Beam / Local Beam | Top-k tree nodes per level / neighbors pooled across k local states |
| Policy / Value Iteration | Policy evaluation and improvement / optimality backup each sweep |
| HMM Forward / Viterbi | Sum of hidden-path probabilities / maximum-probability hidden path |
